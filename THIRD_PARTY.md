# Сторонние компоненты и материалы

BSD-2-Clause в корне относится к собственному коду Memebooru. Она не заменяет следующие условия:

| Компонент | Условия / источник |
|---|---|
| SQLite, `Sources/CSQLite` | Public domain; уведомления в исходниках |
| stb, `Sources/CStbImage` | MIT или public domain по выбору; полный текст в заголовках |
| NanoSVG, `Sources/CNanoSVG` | zlib; уведомления в заголовках |
| Swift Argument Parser, Swift Crypto, Swift Log | Apache-2.0; версии зафиксированы в `Package.resolved`, лицензии в исходных репозиториях зависимостей |
| FFmpeg и его кодеки | Собственные LGPL/BSD и другие лицензии в загружаемых исходниках; сборочные скрипты не делают их BSD-2-Clause. Перед распространением бинарной сборки соблюдайте условия включённых компонентов и предоставления соответствующих исходников |
| Caddy | Apache-2.0; используется официальный Docker-образ |
| Pillow, PyTorch, torchvision, OpenCLIP | Лицензии соответствующих Python-пакетов; нужны только для подготовки коллекции |
| Модель OpenCLIP | `laion/CLIP-ViT-B-32-laion2B-s34B-b79K`; условия и model card у издателя модели |
| Обои Frutiger Aero Archive | Сторонние изображения; права остаются у авторов. URL оригинала и страницы источника сохраняются в манифесте |

Не удаляйте уведомления об авторстве из включённых сторонних исходников. Публичная галерея содержит ссылку на источник и отдельно указывает, что лицензия кода не распространяется на изображения.
